# gh-cli

Enforces authenticated gh CLI workflows over unauthenticated curl, WebFetch, and MCP fetch patterns. Use when working with GitHub URLs, API access, pull requests, or issues.

## Overview

This directory contains the operational guidance for the `gh-cli` skill. Start with [SKILL.md](SKILL.md), which defines when to use it and the workflow it provides.

## Usage
